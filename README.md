# Food Delivery Data Cleaning

A data cleaning project based on a **20,000-row food delivery dataset**, created using Python and Pandas.

## Project Overview

The main goal of this project was to clean and prepare raw food delivery data for further analysis.

## Data Cleaning Tasks

* Checked missing values
* Removed duplicate records
* Cleaned and standardized text data
* Checked data types
* Handled data inconsistencies
* Prepared the dataset for analysis

## Dataset

* **Rows:** 20,000
* **Columns:** 11
* **Domain:** Food Delivery

## Tools Used

* Python
* Pandas
* NumPy
* Google Colab

## Visualization

A few graphs were also created to understand the cleaned data and present the results visually.
